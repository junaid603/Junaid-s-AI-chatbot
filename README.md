🤖 Junaid’s AI Chatbot

An interactive AI chatbot built using Streamlit and Google Gemini API.
It provides a clean chat interface with custom styling and real-time AI responses.

🚀 Features:

💬 Real-time chat with AI (Gemini 2.5 Flash Lite)

🎨 Custom dark-themed UI with styled chat bubbles

🧠 Conversation memory using Streamlit session state

⌨️ Chat input interface similar to modern messaging apps

🤖 Typing animation for better user experience

🔐 Secure API key handling using .env


🛠️ Tech Stack:

Python 🐍

Streamlit 🎈

Google Gemini API 🤖

dotenv 🔐 (for environment variables)

HTML/CSS (custom styling inside Streamlit)
